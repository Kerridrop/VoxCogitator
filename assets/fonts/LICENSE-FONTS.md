# Fonts

Both fonts are embedded into `Cogitator.exe` as resources.

## FSEX.ttf — Fixedsys Excelsior 3.01

Fixedsys Excelsior by Darien Valentine. Released into the public domain;
where that is not possible, under the Creative Commons Zero (CC0 1.0) dedication.
TTF build taken from the `kika/fixedsys` project.
